FORMA v2 — приложение для iPhone в формате PWA

УСТАНОВКА ЧЕРЕЗ GITHUB PAGES
1. Создай публичный репозиторий на GitHub, например forma-app.
2. Загрузи СОДЕРЖИМОЕ папки forma_iphone в корень репозитория (index.html, app.js, engine.js, style.css, sw.js, manifest.webmanifest и папку icons). Не загружай ZIP как один файл.
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. После публикации открой адрес https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/forma-app/ в Safari на iPhone.
5. Safari → Поделиться → На экран Домой → Открывать как веб-приложение → Добавить.
6. Запускай FORMA с экрана Домой. После первой загрузки основные файлы приложения сохраняются для автономной работы.

ДАННЫЕ И РЕЗЕРВНЫЕ КОПИИ
- История хранится в локальном хранилище самого веб-приложения, не на GitHub и не у ChatGPT.
- Регулярно экспортируй JSON в «Файлы» / iCloud Drive с вкладки «Данные».
- Очистка данных приложения, удаление веб-приложения и переезд на другой телефон могут привести к потере записей.
- Предыдущие данные FORMA v1 можно перенести экспортом JSON из старой версии и импортом в новую.
- Отдельный предпросмотр FORMA_preview.html существует только для знакомства; он не заменяет установленное PWA.

«УМНЫЙ» АЛГОРИТМ
- Сверяет историю по каждому упражнению, повторения, вес, запас повторений, самочувствие и давность занятия.
- Предлагает увеличение веса только после двух подтверждающих занятий в верхней границе диапазона и при шаге до 10%.
- Учитывает плохой сон, усталость, болезненные упражнения, перерывы более двух недель и отсутствие прогресса в трёх сопоставимых занятиях.
- Рекомендует объём для 25, 40 или 55 минут.
- Это не нейросеть, медицинское заключение или проверка техники. Любые советы можно проигнорировать.
